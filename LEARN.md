# LEARN.md

## 1. Что сделали  
Создали интерактивный дашборд для анализа личных финансов. Приложение позволяет:  
- Загружать CSV-файлы с данными о доходах и расходах.  
- Визуализировать динамику бюджета с помощью графиков.  
- Анализировать категории затрат.  

Технологии: Python, Pandas, Matplotlib, Streamlit.  

## 2. Что разобрать  
- **Pandas**: работа с DataFrame, группировка данных, агрегация.  
- **Matplotlib**: построение графиков (линейные, столбчатые).  
- **Streamlit**: создание веб-интерфейса без бэкенда.  
- **Архитектура приложения**: разделение логики обработки данных и интерфейса.
