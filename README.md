# Personal Finance Dashboard

Интерактивный дашборд для визуализации ваших личных финансов. Приложение позволяет загружать CSV-файлы с транзакциями, строить графики динамики доходов и расходов, а также анализировать структуру затрат по категориям.

## Запуск

Для работы приложения необходим Python 3.8+. Сначала установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите дашборд командой:

```bash
streamlit run main.py
```

## Пример

1. Подготовьте CSV-файл с колонками `date`, `category`, `amount` и `type` (income/expense).
2. Загрузите файл через интерфейс приложения в браузере.
3. Используйте фильтры для построения графиков по периодам.

## Тесты

Для запуска автоматических тестов выполните:

```bash
python -m unittest discover -s tests -v
```
